# AaditJain_ACMResearchTasks

This repository contains my submissions for the ACM Research Tasks.

## Repository Contents

* `task0/` - Log transformation task implemented in Python.
* `task1/` - Review of an article on Agentic AI and its impact on business.
* `task2/` - Summary and analysis of a research paper.
* `bonus/` - Exploratory Data Analysis (EDA) notebook.

## Running Task 0

Navigate to the `task0` folder and run:

```bash
python transform_logs.py
```

The program will process the log data and perform the required transformations.

## Bonus Task

The `bonus/` folder contains the EDA notebook:

```text
bonus/eda.ipynb
```

The notebook can be opened and executed using Jupyter Notebook, JupyterLab, or Google Colab.
